# FaceSend 分步部署指南

## 第一步：启动环境（MySQL + MinIO）
```bash
cd ~/app/FaceSend/deploy-minimal
sudo docker-compose -f docker-compose-env.yml up -d
sleep 30
```

## 第二步：配置数据库
```bash
sudo docker cp init.sql facesend-mysql:/
sudo docker exec -i facesend-mysql mysql -uroot -p123456 -e "source /init.sql"
```

## 第三步：登录 MinIO 控制台创建桶
浏览器打开 http://你的公网IP:9001
- 账号：minioadmin
- 密码：minioadmin
- 新建 Bucket 叫 facesend

## 第四步：启动 FaceSend 应用服务
```bash
sudo docker-compose -f docker-compose-app.yml up -d --build
```

全部搞定！100% 完全可控！
